Why Mah'a Gnan

Everything you need to run fair, cheat-resistant assessments — for interview screening, coding rounds, or quick MCQ tests.

👀

Face-Verified Proctoring

Every student registers a reference photo, and the camera watches throughout the test — flagging extra people, no-face, and looking-away events automatically.

✅

Instant MCQ Results

Screening tests are auto-graded the second a student submits — score, a personalized performance note, and a full answer review with correct answers shown for every mistake.

🎲

Randomized Question Sets

Each student can get a shuffled subset pulled from a larger question bank, in a unique order — makes screen-sharing or "compare answers" cheating far less useful.

📄

Certificates & CSV Reports

Students can download a result PDF right after their MCQ test. Admins can export full submission and score data to CSV for offline records.

🏆

Opt-in Leaderboard

Turn on a top-scorers leaderboard for any MCQ test — students see how they stack up right after submitting, only when you choose to enable it.

💻

Real Code Editor

Coding questions open in a full syntax-highlighted editor across HTML, CSS, JavaScript, Java, MySQL, and Python — fixed per question or left for the student to choose.
